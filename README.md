# Distracted Driver Detection Research
This repository contains my research on using Machine Learning to identify distracted driving behaviors to improve road safety.

## Overview
- **Objective:** Classify driver behavior into 10 states (texting, talking, etc.) using image data.
- **Models Used:** Decision Trees, SVC, and Logistic Regression.
- **Key Result:** Achieved 72.25% accuracy with the Decision Tree model.

## Dataset
The dataset consists of 2,000 images. Due to file size, it is hosted on Google Drive: [Link to your Drive](https://drive.google.com/drive/folders/1q6ttb00k3MoBo3dfip5kbbnwxKD0rspN?usp=sharing)
