**Dataset**
The dataset used for this project is hosted on Google Drive due to file size constraints. It contains 2,000 images categorized into 10 distinct driver distraction states.

Access the dataset here:[ Driver Distraction Dataset
](https://drive.google.com/drive/folders/1q6ttb00k3MoBo3dfip5kbbnwxKD0rspN?usp=sharing)

**Instructions:**

Download the dataset folder from the link above.

Extract the contents into a folder named dataset/ within the root directory of this repository.

Ensure the file path in the notebook/script matches the location of the extracted images.
